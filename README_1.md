# Инструменты для руководителя

Две небольшие веб-системы, созданные для управления задачами и заметками. Каждая работает как самостоятельная страница — открывается по ссылке, без установки.

## 1. Панель поручений для руководителя

Дашборд для постановки задач сотрудникам с календарём и WhatsApp-напоминаниями.

**Ссылка:** https://claude.ai/artifact/WD4ArfswfukJZ572wWVSc5

### Возможности

- **Единая строка ввода** для руководителя: задание и фамилия исполнителя пишутся одной строкой, система сама находит сотрудника по фамилии; если распознать не удалось — предлагает выбрать вручную
- **Календарь** с автоматически отмеченными красными датами (воскресенья и основные праздники РФ), клик по дню показывает поручения на эту дату
- **Карточки сотрудников**: ФИО, должность, телефон/WhatsApp, заметка — добавление, редактирование, удаление
- **Просмотр по сотруднику**: список всех поручений конкретного человека со статусами «в работе» / «выполнено»
- **Напоминания в день дедлайна**: система показывает, кому сегодня нужно напомнить, и формирует готовую ссылку на WhatsApp с текстом сообщения — остаётся один клик «отправить»
- **Разграничение доступа**: руководитель видит всё и может вносить изменения; сотрудник — только свою карточку и свои поручения, без права редактирования

### Вход

| Роль | Как войти |
|---|---|
| Руководитель | логин `admin`, пароль `admin` |
| Сотрудник | выбор себя из списка (без пароля) |

### Важные ограничения

- **Автоматическая отправка в WhatsApp невозможна.** Нет официального WhatsApp Business API — вместо автоотправки система готовит сообщение и открывает WhatsApp с уже заполненным текстом, отправка — вручную одним кликом.
- **Вход admin/admin — это интерфейсное ограничение**, не полноценная защита данных. Для реальной работы с конфиденциальной информацией нужна отдельная авторизация.
- **Автопоиск сотрудника по фамилии** — простое сопоставление текста. При совпадающих фамилиях стоит сразу выбирать вручную.
- **Красные даты** заданы фиксированным списком (воскресенья + основные праздники РФ) и не учитывают переносы рабочих дней в конкретном году.
- Данные общие для всех, кто открывает ссылку, и хранятся в базе, привязанной к этой странице.

## 2. Календарь заметок

Личный календарь с возможностью оставить заметку на любую дату.

**Ссылка:** https://claude.ai/artifact/4apBtAgtDx1xEC2mRpXWmG

### Возможности

- Клик по любому дню открывает панель для заметки, сохраняется автоматически
- Дни с заметками отмечены точкой
- Список всех заметок для быстрого перехода к дате
- Сегодняшний день выделен, выходные — отмечены цветом

### Важное ограничение

Заметки хранятся локально в браузере, в котором открыта страница — при переходе по ссылке с другого устройства их не будет видно.

## Как поделиться

Обе ссылки открываются напрямую в браузере. Чтобы дать доступ коллегам, отправьте им соответствующую ссылку — открывать код или разворачивать что-либо дополнительно не нужно.
