Инструменты для руководителя

Две страницы для управления задачами и заметками. Откройте нужную ниже.

Панель поручений

Постановка задач сотрудникам с календарём, красными датами и WhatsApp-напоминаниями.

Календарь заметок

Личный календарь с возможностью оставить заметку на любую дату.

Открыто напрямую из этого репозитория через GitHub Pages: данные каждой страницы хранятся локально в браузере, в котором она открыта, и не синхронизируются между устройствами.
